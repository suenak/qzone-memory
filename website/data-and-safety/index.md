# 数据与安全

## 数据在哪里

归档数据库、媒体缓存和导出文件保存在当前设备的应用数据目录或你选择的导出位置。它们不自动上传到项目服务器。

## 登录凭证

登录流程可能使用浏览器 Cookie 与 QQ 空间进行会话。不要在不受信任的设备上登录，也不要将 Cookie、数据库文件或导出文件发送给陌生人。

凭证以加密形式保存在操作系统凭据库（macOS 钥匙串 / Windows 凭据管理器 / Linux Secret Service），不会写入数据库、前端存储或日志。

## 关于授权激活

首次使用需要在激活界面输入账号与密码以绑定设备。激活请求发送给授权服务器，内容仅为设备标识（随机生成的安装 ID，以及硬件标识的哈希值）与账号信息。

**不会上传**你的 QQ 空间归档内容、登录凭证或媒体文件——归档数据始终只存在本机。

激活仅用于设备席位管理。凭证签发后经过签名校验并保存在本地，离线可用；超过宽限期后只会限制新建归档任务，不会影响你已经归档到本地的数据。

## 建议的备份方式

- 对重要归档定期导出 HTML，并保存到受信任的加密存储介质。
- 升级、清理应用数据或卸载前，确认备份可被正常打开。
- 将本工具限制在本人账号或书面获得授权的资料范围内。
