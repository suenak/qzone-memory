# 空间回忆馆：UI 重构交付记录

日期：2026-10-09。范围：现有 Vue 前端、样式、交互呈现和构建分包。

## 1. 产品与平台

将 QQ Zone Restore Archive 的工具界面整理为个人数字回忆档案。主要路径为连接 QQ 空间 → 同步资料 → 按年份翻阅说说与照片 → 查看往来记录 → 导出或保存。回收站恢复、授权管理和危险操作仍保持独立的确认流程。

桌面沿用系统原生窗口，使用侧边导航与顶部工具栏；860px 以下改用底部四个常用入口和“更多”抽屉。Android/iOS 分支仍按实际平台判断，未新增原生窗口协议。

取数和恢复能力依赖原有 QQ 接口。没有互动痕迹或服务端不再返回的内容仍不能恢复，界面不承诺完整备份。

## 3. 设计系统与组件清单

唯一视觉变量来源是 `src/styles/tokens.css`。浅色默认，保留已保存的深色或跟随系统选择。画布浅灰蓝、表面白色、主要操作蓝色；暖色用于回忆语境和时间线。深色以蓝灰表面建立层次，按钮反色文字随主题改变。

正文沿用系统中文无衬线字体，不加载远程字体。间距沿用4px基数，控件、抽屉宽度、阅读宽度、照片网格、阴影和动效均复用语义变量。图标统一使用现有 Lucide，移除 PrimeIcons 依赖与字体文件。

| 组件 | 职责 |
|---|---|
| 新增 ArchiveHeading | 小标题、主标题、描述、可选页面操作 |
| SectionCard | 数据/设置区块，标题、操作、内容、页脚，窄屏换行 |
| EmptyState | 未登录、无记录、无匹配和读取失败，以及下一步 |
| SkeletonBlock | 数据加载占位，保留减少动效支持 |
| StatTile | 真实统计及读取失败占位 |
| ToastHost + useToast | 操作结果反馈 |
| QzoneText | 正文、提及、QQ表情；文本插值安全渲染 |
| PrimeVue | 按钮、选择、输入、密码、Dialog、Drawer、分页等，通过 base.css 映射语义变量 |

可选中历史正文，保留可见焦点与键盘操作。取消了阻止用户缩放的全局手势拦截。移动端主要控件至少48px高，抽屉考虑安全区，Dialog受视口高度约束。

## 4. 业务集成与兼容性

- 使用既有 Pinia 账号、授权、同步和回收站状态，未添加假账号、假接口、演示记录、虚构统计或进度百分比。
- 本轮开始时记录的20个后端/配置文件 SHA-256 均未改变，包括 Rust、Cargo 文件和 Tauri 配置。工作区已有的其他修改没有回退。
- 对原有 Vue 按钮/提交/变更事件做静态对照，未发现原有事件处理入口缺失。此检查不替代原生端到端测试。
- `src/utils/qzone.ts` 的命令名和参数在本轮 UI 工作中未修改，数据库、取数、恢复、登录和授权协议保持原有实现。
- 新增月份、日期范围、仅有图片/互动条件明确标为“筛选已加载内容”。年份和关键词仍调用现有全库查询；细化筛选开启时使用“读取下一批”，避免自动连续扫描全部归档。
- “保存当前预览图”保存已经加载的图片，未把缩略图描述为原图。原有打开媒体方式保留。
- 没有新增埋点、资料上传、远程字体或第三方追踪。
- 增加错误呈现与诊断脱敏；回收站原生窗口卸载清理保留，并防止浏览器预览或清理失败产生未捕获异常。
- 既有轮询、图片观察器、键盘事件和卸载清理保留；新增 Ctrl+K 事件在卸载时解绑。

## 5. 性能与维护

说说与媒体继续增量查询。离屏卡片使用 `content-visibility` 和预估尺寸，旧的图片缓存释放与懒加载机制保留。图库继续采用有限分页，不把全部记录一次挂载。

清理重复样式规则，并将通用容器交由现有基础组件。Vite将 Vue 运行时与 PrimeVue 单独分包，页面仍按路由懒加载；最后构建主入口约85.6KB、Vue运行时约109.8KB、PrimeVue约459.7KB（未压缩传输前的 minified 文件大小），未再触发500KB分包警告。

## 9. 2026-10-09 页面文案与交互调整

延续现有颜色、布局与组件，重点让第一次使用的人看懂入口、下一步和操作后果。界面中的“归档”改为“备份”或“保存”，导航直接使用“说说”“相册”“视频”等内容名称。备份与回收站恢复分别说明，避免把保存现有内容说成恢复已删除内容。

主要调整：

- 首页与各内容页缩短标题和介绍，去掉口号、重复说明和装饰性英文；空状态提供登录、开始备份、清除筛选等实际下一步。
- 搜索支持清除与键盘聚焦，筛选明确只作用于已加载内容；快速切换年份、详情和相册时，忽略旧请求的迟到结果。
- 任务进度共用全局状态，避免重复轮询；失败可重试，原有内容不会因为刷新失败消失。请求间隔直接填写秒，保存时仍使用后端要求的毫秒。
- 日常说说工具栏移除“清空全部”；设置里的清空操作准确标明仅清空当前账号说说，清空说说不会重置外观或请求间隔。任务运行时阻止冲突操作。
- 删除、解绑与停用本机授权分别说明后果；失败留在弹窗内显示，取消和 Esc 可退出，提交期间防止重复点击。
- 授权账号明确区别于 QQ 账号，缺项提示定位并聚焦对应输入框；切换激活和兑换保留已经填写的账号。
- 预览支持 Tab 循环、Esc 关闭与焦点返回；移动端更多菜单有明确名称，选择页面自动关闭。组件默认关闭、翻页等提示改为中文。
- 首次使用先呈现三条重点，完整说明可展开阅读；数据处理说明补充实际授权请求，更新须知版本后重新确认。

## 10. 2026-10-09 授权到期日修复

原客户端把设备凭证的30天续签期限显示为账号到期日，导致后台分配一年、客户端只显示一个月。服务端现在在签名中单独携带账号到期日 `aexp`，客户端的到期日及剩余天数读取该字段；永久账号显示“永久有效”。设备凭证的 `exp`、离线宽限与验签规则保持原有机制。
