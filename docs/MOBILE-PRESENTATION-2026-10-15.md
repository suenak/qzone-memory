# 手机页面展示调整

## 范围与设计

调整说说、相册和恢复任务三个页面，保留蓝灰色主题及说说的实际年份分组。手机内容区使用全宽卡片，次要工具按需展开；桌面继续使用原有多列布局。恢复、登录、软件授权及媒体请求的数据协议保持原样。

- 说说：压缩工具区，批量选择、导出、展示方式及高级筛选放进“筛选与导出”；保留搜索、分类、年份、排序和刷新入口。移除手机时间轴左侧占位，整理作者、日期、图片与评论间距。
- 相册：手机改为 96px 方形封面与标题并排的列表；删除与标题重复的摘要及媒体地址数量标记。失败封面保留“重试封面”，骨架屏使用相同尺寸，避免封面加载前后跳动。
- 恢复任务：缩小状态图标，统计采用两列布局；主操作占整行，“停止恢复”和“跳页记录”保留明确名称。长诊断默认收起，可展开查看，仍经过凭据信息过滤。手机的每页间隔设置分行显示。
- 相册恢复单一页面根节点，使现有切页动效正常工作，消除 Transition 无法作用于多根节点的警告。

改动位于 `src/views/ArchivesView.vue`、`src/views/LibraryView.vue`、`src/views/TasksView.vue` 和 `src/styles/tokens.css`。

## 验证

- `npm run build` 通过（Vue 类型检查与 Vite 生产构建）。存在原有 plugin-opener 同时被静态和动态导入的分包提示，不影响构建。
- `git diff --check` 通过。
- Chromium 页面验收使用明确的模拟 IPC 数据及示意图片，不读取真实 QQ 账号资料。48 项布局与交互断言通过：320、360、390、430、844、1440px 宽度，横屏、深浅色、140% 字号、空列表、任务各状态、未登录提示、键盘展开工具与任务详情，以及封面重试。
- 另外 5 项状态流程通过：慢加载骨架、加载完成、列表失败后重试、图片预览 Escape 关闭、无页面异常或无效切页根节点警告。骨架封面尺寸另核对为 96×96px。
- 相册搜索、年份和刷新控件在手机布局下至少 48px 高；窄屏与大字号检查筛选控件不重叠。新折叠入口与详情支持键盘操作，继续使用全局焦点及减少动效规则。

本机证据位于工作区 `output/playwright/mobile-polish-*.png`、`mobile-polish-checks.log`、`mobile-polish-states.log`，构建日志为 `output/mobile-polish-build.log`。验证脚本在同一 `output/playwright` 目录。
